# 景点图片来源清单

核验日期：2026-08-09。

本次共核验 76 个全国景点、83 个路线景点，以及个人页中的岳阳楼和后母戊鼎图片。路线景点中 40 个复用全国资源，独有图片共 121 张。所有最终图片均为公开网页中的真实摄影照片，不包含 AI 生成图片；优先选择可明确辨认主体的照片，无法取得标志性主体时仅使用来源页、分类或坐标可确认位于景区范围内的普通实景。

图片下载后统一转换为 WebP 并由项目本地路径引用。Wikimedia Commons、Flickr 等来源的版权仍由各作者持有，使用时应遵守下表许可证；本清单不构成法律意见。
