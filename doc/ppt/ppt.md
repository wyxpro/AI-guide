## 4. AI能力（模型、RAG检索与工作流程）

### 1. 检索增强生成 (RAG) 混合重排工作流

```
  用户提问 ───────┐
                 ▼
  [ RAG 知识检索 (vectorized=true) ] 
                 │
                 ├──► 1. 余弦相似度 (Cosine Similarity) 计算 ───┐
                 │                                               ├─► 混合重排评分 (0.7*语义 + 0.3*关键词)
                 └──► 2. 关键词匹配度 (Keyword Score) 计算 ──────┘
                                 │
                                 ▼
                     筛选过滤评分 >0.2 并提取 Top-3
                                 │
                                 ▼
                    召回知识片段注入 LLM System Prompt (防幻觉)
                                 │
                                 ▼
                           DeepSeek 生成
```

### 2. 多模态数字人伴游工作时序

```
游客麦克风录音 ──► Web Audio API ──► STT 语音识别 ──► 混合 RAG 检索 ──► 注入 Prompt
                                                                           │
                                                                           ▼
频域口型同步 ◄── AnalyserNode ◄── Edge-TTS 流式发音 ◄── 识别分句 ◄── SSE 实时字符流 
```

*   **流式切句**：为降低 TTS 首音延迟，在检测到句号、感叹号、问号等标点时立即发起合成，首音时延缩短至 **1.8秒**。
