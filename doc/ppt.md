## 3. 用户画像

> 针对不同的游览诉求，系统提供 **普通 / 银发 / 儿童** 三大专属无障碍模式，自动适配不同的界面字体、语速以及内容风格。

### 🏷️ 四大核心用户群体分析

*   **🧓 银发漫步族 (60+ 岁老年人)**
    *   *需求场景*：行动缓慢、体力受限、听觉退化。
    *   *系统策略*：自动进入**银发模式**（字号放大至 20px，语速降至 0.8x，线路规划优先过滤台阶，突出公厕和休憩长椅）。
*   **👩‍👦 亲子出行组 (30-40 岁家长与学龄前儿童)**
    *   *需求场景*：游玩趣味度要求高、小童体力弱。
    *   *系统策略*：激活**儿童模式**（拟人活泼语气，加入童趣小故事讲解，重点标注滑梯和游乐点，限制字数在 100 字内）。
*   **📜 文史探索者 (历史/考古文化拥趸)**
    *   *需求场景*：注重考证精准性，拒绝 AI 虚假信息。
    *   *系统策略*：开启**学术模式**（RAG 检索权重拉满，在回答末尾附带知识库原始文档出处及相关文物索引引用）。
*   **⚡ 自由行特种兵 (18-30 岁青年游客)**
    *   *需求场景*：注重打卡速度、社交分享、拍照角度。
    *   *系统策略*：开启**效率模式**（自动推荐最短时间路线、最佳摄影机位，启用 VR 拍照即识瞬间定位景点历史）。

# 三、技术解析及亮点 🧠

## 4. AI能力（模型、RAG检索与工作流程）

### 1. 深度整合 RAG 检索防幻觉工作流

```
用户提问 ──> 余弦相似度计算 ──> 混合重排 (0.7语义+0.3关键词) ──> Top-3 召回注入 LLM Prompt ──> SSE 文本流
```

### 2. 交互智能体 (Agent) 端到端响应工作时序

```
                              【 Agent 交互时序闭环 】
                              
 🎙️ 录音识别 (ASR)           🤖 RAG 拼装与大模型推理        💬 SSE 输出与情感检测       🔊 音画唇形同步
 捕获麦克风输入 wav ──>  匹配本地景区文档 ──>  大模型流式响应 ──>  提取情感标签(如[愉快]) ──>  驱动 Live2D 表情动作
                         限制输出字符长度      过滤后显示在单气泡中  TTS 流式切句发音 ──>  AnalyserNode 频域口型
```

*   **情感解析机制**：API 拦截首行 `[情感: 愉快]` 标记并不予渲染，直接触发前台数字人表情与动作包。
*   **流式切句**：为降低 TTS 首音延迟，在检测到 `。` `！` `？` 等标点时立即切句发起合成，延迟降至 **1.8秒**。
