# 🤖 旅行家 · 景区AI数字人导游与运营系统平台 — 全面产品分析

## 🌟 一、产品概述

### 1. 📖 项目背景

随着文旅产业的数字化转型加速，传统景区面临导游人力成本高、服务标准化难、个性化体验缺失等核心挑战。人工导游受限于工作时间与精力，无法为每位游客提供深度定制化讲解；传统语音导览App仅支持单向音频播放，缺乏交互能力与智能推荐。在大模型（LLM）、多模态视觉识别、流式语音合成（TTS/STT）等AI技术快速成熟的背景下，**旅行家**应运而生——以AI数字人为核心交互中枢，重新定义智慧景区导览体验。

### 2. 📋 项目简介

| 维度 | 内容 |
|------|------|
| **项目名称** | 旅行家 · 景区AI数字人导游与运营系统平台 |
| **项目简介** | 面向智慧景区的双端（C端游客 + B端运营）智能导游与数字化管理系统，以7×24小时在线AI数字人为交互核心，融合LBS定位、LLM大模型、流式TTS/STT、多模态视觉分析等技术，提供沉浸式一站式游览伴随服务 |
| **核心价值** | 游客端：个性化AI导览、智能行程规划、VR即拍即识；管理端：实时数据大屏、RAG知识库管理、数字人形象配置、运营分析决策 |

### 3. 🎯 痛点价值

## 📸 四·一、VR即拍即识 —— 详细解析与代码实现

### 📌 功能概述

VR即拍即识是旅行家平台的**核心特色功能**，集成 DeepSeek-VL（Vision-Language）多模态视觉大模型，让游客通过拍摄任意展品或建筑照片，在数秒内获得**深度文化脉络解读**、历史渊源介绍以及专业游览建议。该功能将传统"走马观花"的游览方式升级为"沉浸体悟"的智慧文化体验。

### 🌐 后端API实现详解

**接口地址：** `POST /api/spots/recognize`  
**Content-Type：** `multipart/form-data`

#### 完整处理流程

```typescript
// 1. 接收图片文件
const formData = await request.formData();
const imageFile = formData.get("image") as File;

// 2. 图片转Base64编码（适配多模态API要求）
const arrayBuffer = await imageFile.arrayBuffer();
const base64 = Buffer.from(arrayBuffer).toString("base64");
const mimeType = imageFile.type || "image/jpeg";

// 3. 构造多模态Prompt（系统角色设定 + 结构化输出要求）
const systemPrompt = `你是翠玉景区的专属AI导览员小玉...
请分析图片，识别其中的景物、建筑、植物或自然风光：
1. 说出识别到的主要景物（30字内）
2. 介绍相关历史文化背景或趣味知识（100字内）
3. 给出游览建议或拍照技巧（50字内）
请用JSON格式回复：{ subject, story, tip }`;

// 4. 调用 DeepSeek-VL 多模态API
const response = await ai.chat({
  model: "deepseek.v3.1",
  messages: [{
    role: "user",
    content: [
      { type: "text", text: systemPrompt },
      { type: "image_url", image_url: { url: `data:${mimeType};base64,${base64}` } }
    ]
  }],
  max_tokens: 600,
});

// 5. 解析JSON结构化结果
const raw = response.choices?.[0]?.message?.content ?? "";
const match = raw.match(/\{[\s\S]*\}/);  // 提取JSON部分
result = JSON.parse(match[0]);            // { subject, story, tip }
```

#### Prompt Engineering 设计要点

| 设计维度 | 具体策略 | 目的 |
|---------|---------|------|
| **角色设定** | "翠玉景区的专属AI导览员小玉" | 确保回答风格一致、温暖亲切 |
| **上下文注入** | `contextSpot` 参数传递当前参观位置 | 识别结果与当前景点关联 |
| **结构化输出** | 要求JSON格式 `{ subject, story, tip }` | 前端可直接渲染，无需额外解析 |
| **字数控制** | 分别限制30字/100字/50字 | 保证信息密度，避免冗长 |
| **三段式回答** | 景物识别→文化背景→游览建议 | 从"是什么"到"怎么看"递进 |
