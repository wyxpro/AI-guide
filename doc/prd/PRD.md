# 产品需求文档 (PRD)

> **产品名称**：旅行家Pro (Voyager Pro)  
> **产品定位**：多模态AI数字人导游与智慧景区运营平台  
> **版本**：V1.0  
> **更新日期**：2026-06-30

---

## 一、产品概述

### 1.1 项目简介

| 字段 | 内容 |
|------|------|
| **产品名称** | 旅行家Pro (Voyager Pro) |
| **产品形态** | C端游客伴游小程序/H5 + B端景区智慧运营管理后台 |
| **产品定位** | 以7×24小时在线AI数字人"小玉"为核心交互入口，融合语音/文本/视觉多模态能力，为游客提供沉浸式智能导览服务；同时为景区运营方提供数据驱动的运营决策看板 |
| **核心价值** | 解决景区导游资源稀缺、信息单向传递、缺乏情感连接、管理盲区四大痛点 |

### 1.2 目标用户与使用场景

| 用户群体 | 典型画像 | 核心场景 | 核心诉求 |
|---------|---------|---------|---------|
| **C端：深度文旅爱好者** | 25-40岁，喜欢自主探索，对历史文化有浓厚兴趣 | 进入景区后与AI数字人对话，询问景点历史背景；根据个人兴趣获取深度讲解路线 | 个性化路线推荐、深度文化讲解、避坑指南 |
| **C端：带娃家庭游客** | 30-45岁，亲子出游，需要兼顾孩子体验与游览效率 | 通过童趣模式与数字人互动，获取亲子友好路线、儿童科普讲解 | 趣味化讲解、无障碍设施指引、亲子路线规划 |
| **C端：银发长辈游客** | 60岁+，行动相对不便，需要更贴心服务 | 使用适老模式，获取大字界面、平缓路线、语音慢速讲解 | 大字体、无障碍路线、舒缓语音、简单操作 |
| **B端：景区管理部门** | 景区运营人员、管理决策层 | 通过管理后台查看当日运营数据、热门问题、游客情感趋势；更新知识库内容；配置数字人形象 | 数据化运营、游客洞察、内容管理、数字人品牌定制 |
| **B端：景区现场客服** | 一线服务人员 | 查看游客高频问题，提前准备标准话术；通过QR码快速响景点咨询 | 实时问题预警、标准应答支持 |

### 1.3 痛点与价值

| 痛点维度 | 当前行业问题 | 旅行家Pro解决方案 | 价值 |
|---------|------------|-----------------|------|
| **导游资源稀缺** | 黄金周/旺季专业导游供不应求，游客体验大打折扣 | AI数字人7×24在线，无限并发服务，无人力成本压力 | 降低景区人力成本80%+，确保服务质量一致性 |
| **信息单向传递** | 传统录音导览内容固定，无法互动解答个性化问题 | 多模态AI实时对话，RAG向量知识库保证回答准确性 | 游客问题即时响应，个性化解答 |
| **缺乏情感连接** | 冰冷设备难以提供真人导游般的亲切感 | Live2D数字人+情感识别+个性化音色，营造情感陪伴 | 提升游客沉浸感与满意度 |
| **管理盲区** | 景区管理者难以量化评估服务质量，无法获取游客真实反馈 | 数据大屏+情感分析+AI运营建议，实现数据化决策 | 运营效率提升，精准优化服务 |

### 1.4 竞品调研

| 竞品/参考 | 产品类型 | 优势 | 劣势 | 旅行家Pro差异化 |
|----------|---------|------|------|----------------|
| **传统景区导览机** | 硬件租赁 | 成本低、无需网络 | 内容固定、无互动、体验差 | AI驱动、多模态交互、内容动态更新 |
| **高德/百度地图** | LBS导航 | 定位精准、路线规划 | 无景区深度内容、无情感互动 | 景区专属知识库、数字人情感陪伴 |
| **景区官方小程序** | 信息展示 | 官方权威 | 功能单一、无AI能力 | AI智能问答+数字人+个性化推荐 |
| **ChatGPT类通用AI** | 通用对话 | 知识广 | 无景区专属知识、无导览场景优化 | 景区专属RAG知识库、多模态导览场景 |
| **其他数字人方案** | 虚拟形象 | 形象丰富 | 多为营销场景，缺乏导览垂直能力 | 垂直景区导览场景+完整管理后台 |

## 五、技术架构

### 5.1 整体架构（前后端分离 + 多端适配）

| 层次 | 技术选型 | 说明 |
|------|---------|------|
| **前端层** | Next.js 16 + React 19 + TypeScript | 服务端渲染(SSR) + 客户端自适应，支持PC/移动端 |
| **UI框架** | Tailwind CSS v4 + Shadcn UI + Framer Motion | 响应式设计 + 丰富动效 |

| **数据库层** | PostgreSQL 16 + Drizzle ORM | 关系型数据存储，类型安全 |
