# 翠玉AI智能导游系统 · 新增必备功能与特色功能开发计划 (pb1.md)

基于已完成的功能分析 (fx.md) 与竞品深度调研 (pa1.md)，本项目后续将围绕“实用性增强”、“体验拟真化”和“文旅商业化”三个核心价值维度，推进全新阶段的功能开发。

---

## 一、 后续开发计划大纲

整个路线图规划为三个执行阶段：
1. **第一阶段：核心基础补完与无障碍 (P1)**：完成地图、无障碍字号缩放、高品质语音组件及B端核心解析的开发。
2. **第二阶段：文旅商业闭环与趣味打卡 (P2)**：完成基于大模型的商户导流、优惠券系统以及电子印章盖章玩法的开发。
3. **第三阶段：多模态前沿体验与离线保障 (P3)**：完成AR镜头识景、PWA离线伴游和写实数字人互动的研发。

---

## 二、 新增功能开发计划表 (必备与特色功能)

下表详细定义了各项新增功能的输入、输出、对应技术栈以及开发优先级：

| 编号 | 功能模块 | 具体开发任务 | 输入 (Input) | 输出 (Output) | 技术栈 (Tech Stack) | 优先级 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **01** | **核心导览** | **实时地图伴游与到站定位广播** | 游客实时经纬度 (GPS API)、景区景点 GeoJSON 围栏坐标。 | 网页交互式地图（当前位置大头针、推荐游览路径折线、到站自动语音播报）。 | `Leaflet.js` / `Mapbox GL` + `turf.js` + Web Geolocation API | **P1 (必备)** |
| **02** | **AI 语音交互**| **高拟真云端语音合成 (TTS)** | 大模型输出的纯文本回复。 | 自然、富有情感起伏的 MP3 语音音频流。 | `ElevenLabs API` / `Azure TTS SDK` + Web Audio API | **P1 (必备)** |
| **03** | **管理中台** | **高级知识库文档解析器** | 管理员上传的 PDF / Docx 格式文件。 | 自动切分并标记的知识库纯文本段落（导入数据库待向量化）。 | `pdfjs-dist` (PDF解析) + `mammoth.js` (Word解析) + Drizzle ORM | **P1 (必备)** |
| **04** | **无障碍适配**| **多模式视觉自适应系统** | 用户在个人中心选定的 accessibility 偏好 (如适老、童趣模式)。 | 全局 CSS 根字号比例缩放 (放大 1.2-1.5 倍)、高对比度配色主题及界面插画切换。 | CSS Variables + React Context / Zustand + Tailwind CSS | **P1 (必备)** |
| **05** | **运营决策** | **大屏统计指标自动累加管道** | 游客端的打卡操作、QA 交互事件、评分提交请求。 | 后台 `analytics_daily` 数据表记录自动合并累加，更新大屏折线图。 | PostgreSQL Triggers / Node Cron + Next.js Middleware + Drizzle ORM | **P1 (必备)** |
| **06** | **文旅商业化**| **AI对话商户导流与动态券** | 游客提问上下文（如“附近有什么餐馆”）、用户兴趣标签。 | 大模型智能推荐附近的合作商户，前端渲染出带有动态条形码/二维码的专属折扣优惠券。 | `Drizzle ORM` + `canvas` (条码渲染) + deepseek context injection | **P2 (特色)** |
| **07** | **趣味互动** | **剧情式数字印章收集系统** | 游客在景点现场扫码打卡请求或地理围栏触发事件。 | 收集到的景点精美手绘 SVG 电子印章，点亮足迹盖章本。 | React Spring (翻页动效) + Framer Motion + 数据库打卡记录关联 | **P2 (特色)** |
| **08** | **弱网保障** | **离线 PWA 景区包** | 游客在 WiFi 状态下点击“下载离线包”请求。 | 离线可读的景点图文介绍、缓存在本地的导游讲解音频，可在离线状态下实现部分伴游。 | `next-pwa` + Service Worker Cache Storage API + IndexedDB | **P2 (特色)** |
| **09** | **AI 多模态** | **AR 实景拍照识景** | 游客打开手机摄像头捕获的景点实物图像帧。 | 智能识别出的景点名称，关联自动唤起小玉进行深度背景知识介绍。 | WebRTC MediaDevices API + Google Gemini Pro Vision API / CLIP API | **P3 (特色)** |
| **10** | **拟真数字人**| **2D 写实数字人音视频连麦** | 游客与 AI 助手的实时音频输入。 | 超低延迟（<1s）的写实 2D 拟真形象视频流，嘴型与大语言模型音频完美同步。 | `HeyGen Interactive Avatar SDK` / `D-ID Streaming API` + WebRTC | **P3 (特色)** |

## 三、 功能开发执行计划 (里程碑)

### 阶段 1：基础完善 (第 1 - 2 周)
- 集中力量攻克 **01 (实时地图)** 与 **03 (高级知识库解析)**。
- 引入 **04 (全局无障碍视觉自适应)**，落实“适老模式”的物理放大。
- 对接 **02 (云端 TTS)**，解决内置 SpeechSynthesis 的机械发音缺陷。

### 阶段 2：商业运营与互动 (第 3 - 4 周)
- 修改数据库结构，创建优惠券表与商户表，上线 **06 (商户导流与动态券)**。
- 联合打卡足迹，上线 **07 (集章打卡系统)**，并配置盖章本翻页微动效，增加黏性。
- 编写后台自动统计 Cron，打通 **05 (指标自动累加管道)**，使大屏真正联动。

### 阶段 3：体验突破 (第 5 - 6 周)
- 启动 **08 (PWA 离线模式)** 配置，保障山林/隧道弱网下的核心导览无碍。
- 引入多模态，打通 **09 (AR拍照识景)**，提升现场科技感。
- 开展 **10 (2D写实数字人流式对讲)** 的接口预研，发布 VIP 体验区。
