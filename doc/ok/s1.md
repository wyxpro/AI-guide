# 📖 第一部分：产品使用手册 (User Operation Manual)

## 📱 一、C端游客移动伴游端 (Consumer App)

C端采用响应式移动端 UI 设计，配色为宣纸暖米底色加上山林绿主题，界面风格温暖大方。

### 1. 欢迎引导与适老无障碍配置 (`/welcome` & `/ai-settings`)
*   **新用户引导**：首次访问系统将进入高保真沉浸式欢迎引导界面，系统提供景点精美图片滚动和主功能轮播。
*   **AI 偏好设置**：游客可进入设置菜单，在三类自适应模式中进行切换：
    *   **普通模式 (`normal`)**：温婉专业的向导语气，标准字号，配音采用自然流式女声，内容详实生动。
    *   **银发无障碍模式 (`elder`)**：
        *   界面文字全局放大至 `20px` 以上，图标间距增加防止误触。
        *   数字人语音语速调慢（0.8x），语气更慈祥平缓。
        *   **智能避障**：在进行行程规划时，系统后台自动过滤台阶、陡坡等高体能要求景点，优先规划带有平缓坡道、无障碍电梯、以及休憩座椅和公厕的路线。
    *   **童趣儿童模式 (`child`)**：
        *   界面自动切换为活泼可爱的卡通动效背景。
        *   数字人“小玉”回答被限制在 `100字` 以内，采用充满爱心与想象力的拟人化词汇（如称呼“揽月亭”为“月亮婆婆的遮阳帽”，称呼“古窑遗址”为“泥土宝宝的桑拿房”），并搭配轻快活泼的童趣配音。

### 2. 7x24h 数字人 RAG 问答互动 (`/qa`)
*   **口型同步数字人**：小玉静态形象位于界面中央，支持流式对话响应。当 AI 发声时，系统通过 Web Audio `AnalyserNode` 解算音频振幅，实时改变嘴部贝塞尔曲线，达成毫秒级音画口型对齐。
*   **单气泡内嵌打字流**：
    *   常规问答在生成答案前会有双气泡闪烁的视差痛点，旅行家Pro独创**单气泡融合方案**。
    *   未输出文本时，气泡中展示三个弹跳加载点（`bouncing dots`）；文本开始传输瞬间，原地流畅渐变为打字机输出流（`typewriter effect`），无感切换。
*   **语音输入**：支持按下录音按钮，进行实时语音录入（STT），转换为文字后自动送入 AI 推理。

### 3. 智能行程规划与地图纠偏 (`/routes`)
*   **智能生成**：游客输入偏好标签（历史/自然/亲子）与理想游玩时间，大模型调用 JSON Mode 输出途经的景点 ID 序列，并通过 `@turf/turf` 空间算法计算出总路线的球面位移（总长度）与预计时间。
*   **地图渲染**：在重庆高精度的 3D 模拟地图组件上动态绘制 Polyline 路线折线。
*   **实时纠偏**：如果检测到游客当前经纬度大幅偏离规划路线（距离 > 50 米），系统会自动触发纠偏警示并通知小玉重新计算接续路径。

### 4. VR 拍照即拍即识 (`/vr-recognize`)
*   **LIDAR 仿真扫描**：游客对景区石碑、碑刻、建筑拍照上传，界面会运行 4 阶段的 3D 激光雷达拓扑网格扫描动画。
*   **多模态分析**：后台识别 API 接收图像后，调用 Step-3.7-Flash 视觉大模型进行分析，秒级输出该文物的历史典故、烧制年代和艺术特色，并自动唤醒 Edge-TTS 进行真人朗读。

### 5. 景区 FM 与趣味足迹打卡 (`/fm` & `/profile`)
*   **FM 广播**：类似于电波节目，流式生成景区逸闻故事，并分集进行语音播报。
*   **足迹勋章**：游客每到达一个景点，手机 GPS 触发地理围栏判定到访，系统发放对应的足迹打卡勋章（如“攀登勇士”、“文化传人”），极大地增强了游玩趣味性。

## 🖥️ 二、B端景区智慧运营管理后台 (Administrative Portal)

B端管理后台位于 `/admin`，供景区运营主管进行实时客流监控、系统维护与数字人装扮。

### 1. 智慧景区实时数据大屏 (`/admin`)
*   **客流折线图**：展示今日实时进园人数、高峰期客流分布曲线（由 SVG 自适应渲染）。
*   **满意度情感大饼图**：自动分析游客提问日志中的负面、中性、正面占比。
*   **高频词云实时分析**：动态展示近 24 小时内游客咨询最多的关键词词云，帮助运营者瞬间掌握景区热点（如“票价”、“轮椅通道”）。

### 2. RAG 向量知识库一键维护 (`/admin/knowledge`)
*   **文档上传与解析**：支持景区管理员直接上传 PDF、Word、TXT 格式的景区最新变动文件（如“关于听松轩因修缮暂停营业的通知”）。
*   **自动向量化 (Embedding)**：文档解析成文本块后，自动调用 OpenAI / Eazo API 进行文本向量化，并打上 `vectorized=true` 标签存入数据库，供 RAG 问答即时检索，杜绝 AI 讲解幻觉。

### 3. 景点数据 CRUD 管理 (`/admin/spots`)
*   提供可视化地图标点工具。支持景点名称、经纬度坐标、语音指引配置、推荐游览时长、景区分分类标签的一键新增、删除与修改。

### 4. 数字人形象装扮与配音定制 (`/admin/avatar`)
*   **自适应配置大屏**：左侧预设列表，中间形象选择，右侧音色和欢迎语属性调整，锁死 Flex 宽度，任何屏幕分辨率下均不会发生多列挤压折行。
*   **欢迎语定制**：在此处修改的欢迎语会实时写入 `avatar_configs` 数据库，游客端刷新后小玉的第一句话便会瞬间更新。

# ⚙️ 第二部分：产品部署手册 (Product Deployment Guide)

## 🛠️ 一、开发环境一键自动部署 (Windows OS)

项目根目录下集成了高度自动化的配置脚本 `run.ps1`。如果您的开发环境是 Windows，只需运行该脚本即可一键完成环境检测、依赖安装和数据库初始化。

1.  **打开 PowerShell**：以管理员权限打开 Windows PowerShell。
2.  **进入项目根目录**：
    ```powershell
    cd E:\Code\AI\Start\Web\AI-guide
    ```
3.  **解除执行限制并运行脚本**：
    ```powershell
    powershell -ExecutionPolicy Bypass -File .\run.ps1
    ```
4.  **该脚本会自动执行以下流程**：
    *   **包管理器检测**：优先寻找 `bun` 命令。若检测不到，则输出警告并降级使用 `npm` 进行后续编译。
    *   **环境变量检测**：检查 `.env` 文件是否存在。如果不存在，则复制 `.env.example` 并生成一份全新的 `.env` 配置文件。
    *   **安装依赖包**：执行 `bun install` / `npm install`。
    *   **数据库同步**：自动执行 Drizzle 迁移（`db:generate` + `db:migrate`）。如果发生 schema 不一致报错（例如远程数据库中已经存在表结构），脚本将自动捕获异常并执行 `db:push`，强行将本地最新的 Drizzle schema 同步至 PostgreSQL。
    *   **启动服务器**：编译完成后，执行 `bun run dev` 或 `npm run dev` 启动本地 Next.js Turbopack 编译内核，默认监听 `http://localhost:3000`。

## ⚙️ 二、手动搭建开发环境 (多平台适用)

若需在 Linux/macOS 上部署，或希望逐步手动排查错误，可参考本节步骤。

### 1. 安装核心运行时环境
项目推荐使用 `Bun` 作为 JavaScript 运行时（比 Node.js 构建速度提升近 4 倍）。
*   **安装 Bun**：
    *   *Windows (PowerShell)*:
        ```powershell
        powershell -c "irm bun.sh/install.ps1 | iex"
        ```
    *   *macOS / Linux*:
        ```bash
        curl -fsSL https://bun.sh/install | bash
        ```
*   **或安装 Node.js**：请确保 Node.js 版本 `>= 18.17.0`。

### 2. 克隆项目与安装包依赖
```bash
# 复制配置文件
cp .env.example .env

# 安装依赖
bun install   # 或者使用 npm install
```

### 3. 配置核心环境变量 (`.env`)
打开 `.env` 文件，填入对应的第三方 API 密钥与数据库链接：

```env
# 1. Drizzle ORM 使用的 PostgreSQL 连接字符串 (支持 supabase, neon 等云数据库)
DATABASE_URL="postgresql://username:password@localhost:5432/travel_db"

# 2. Eazo 开放平台配置 (用于游客会话鉴权和私钥解密)
EAZO_APP_ID="your_eazo_app_id"
EAZO_PRIVATE_KEY="your_eazo_private_key"

# 3. DeepSeek 主对话模型配置
DEEPSEEK_API_KEY="sk-your-key-here"
DEEPSEEK_PROXY_URL="https://eazo.ai/api/innoreation/v1/proxy" # 代理中继地址

# 4. StepFun 视觉多模态大模型配置 (用于 VR 拍照即拍即识)
STEP_API_KEY="your_stepfun_api_key"
```

### 4. 初始化数据库与种子数据填充
确保您的 PostgreSQL 数据库已启动且外网可以正常链接。接着在项目根目录下依次执行：
```bash
# 1. 根据 schema 文件生成 SQL 迁移日志
bun run db:generate

# 2. 将 SQL 迁移日志导入数据库中，创建 spots, routes 等表结构
bun run db:migrate

# 3. 运行数据库种子填充脚本，写入预设景点数据、初始数字人参数及前7天模拟客流分析日志
bun run seed.ts
```

### 5. 启动本地开发服务
```bash
bun run dev  # 或者 npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可使用系统。

## ☁️ 三、生产环境 Vercel 自动化部署

旅行家Pro 基于全栈 Next.js 16 架构开发，能够无缝托管部署于 Vercel 云平台。

### 1. Vercel CLI 命令行一键部署
```bash
# 全局安装 Vercel 工具链
npm install -g vercel

# 登录 Vercel 并进行项目关联部署
vercel --prod
```

### 2. 填写云端生产环境变量
在 Vercel 网页后台进入项目设置（`Project Settings` -> `Environment Variables`），添加以下变量：
*   `DATABASE_URL` (请确保为生产库)
*   `EAZO_APP_ID` & `EAZO_PRIVATE_KEY`
*   `DEEPSEEK_API_KEY` & `DEEPSEEK_PROXY_URL`
*   `STEP_API_KEY`
*   `CRON_SECRET` (生成一个长高熵安全字符串，例如 `openssl rand -hex 32`)

### 3. Vercel Cron 定时任务配置
项目根目录下包含 `vercel.json` 规则：
```json
{
  "crons": [
    {
      "path": "/api/notifications/cron/daily-digest",
      "schedule": "0 17 * * *"
    }
  ]
}
```
*   **机制**：每天 UTC 17:00 (北京时间凌晨 01:00)，Vercel 会自动向服务端点 `/api/notifications/cron/daily-digest` 发送带有 `Authorization: Bearer ${CRON_SECRET}` 校验头部的请求。
*   **任务**：该接口自动拉取昨天的全部游客问答 QA 日志，利用 AI 大模型进行批量情感分词归类（负面/正面），写入 `analytics_daily` 表，自动更新 B 端智慧运营大屏的数据曲线，无需人工手动结算。

## 🔌 四、外部 Agent 接入配置 (MCP Model Context Protocol)

旅行家Pro 开创性地挂载了 **Model Context Protocol (MCP)** 标准，允许外部的 AI Agent 直接访问景区数据资产。

### 1. 配置端点
MCP 协议的服务端映射于接口 `/api/mcp`。

### 2. 支持的工具方法集 (Tools)
外部大模型智能体可以直接调用以下 7 个工具，与景区核心数据进行无缝交互：

| 工具名称 | 输入参数示例 (JSON) | 核心职责 |
| :--- | :--- | :--- |
| `list-spots` | `{ "category": "nature" }` | 获取当前景区的景点列表及基本概况 |
| `get-spot` | `{ "spotId": 1 }` | 获取指定景点的深度历史文献和语音指引链接 |
| `list-routes` | *无* | 获取已公开的推荐旅游路线（含总距离和耗时） |
| `ask-question` | `{ "question": "揽月亭什么时候修的？" }` | 让大模型结合景区本地 RAG 知识库回复问题 |
| `add-favorite` | `{ "spotId": 2 }` | 对指定景点进行收藏打卡 |
| `record-visit-rating` | `{ "spotId": 1, "rating": 5 }` | 上报游客对某景点的体验满意度评分 (1-5分) |
| `book-ticket` | `{ "spotId": 5, "date": "2026-07-15" }` | 预订某场馆或景点的入园门票 |
