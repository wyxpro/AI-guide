## 1. Demo 简介

### 💻 产品形态与技术底座
**旅行家Pro (Voyager Pro)** 是一款专为现代化智慧景区深度定制研发的**双端智能伴游与数字化管理运营系统**。
系统依托全栈 **Next.js 16 (App Router) + React 19**，底层配合 **PostgreSQL 16** 和 **Drizzle ORM**，融合多模态大语言模型（DeepSeek-V4-Pro、Step-3.7-Flash）与流式音频技术，提供毫秒级音画口型对齐的数字人伴游。

### 👥 面向的核心用户群体
*   **C端游客**：特别是面临数字鸿沟、体能受限的老年游客（银发族），以及携童出行的家庭游客、追求严谨历史史料的学者和自由行青年。
*   **B端景区运营方**：需要实现全方位客流监控、满意度调优、数字人色声装扮与 RAG 向量知识库即时热更新的景区管理部门。

### ⚡ 三大核心功能展示
1.  **🙋 适老/儿童三模式自适应数字人伴游**：
    *   小玉 7×24h 随时在线，支持流式 SSE 问答与 TTS 真人发声，通过 Web Audio 频域解算动态绘制嘴部贝塞尔曲线，口型毫秒级同步。
    *   **银发模式**自动放大字号至 `20px`，减缓语速（0.8x），在行程规划时**自动避障**过滤台阶、陡坡等，优先推荐有缓坡与公厕的无障碍通道；**儿童模式**则进入卡通风格，大模型以拟人童趣故事（如大树爷爷、石头将军）交互，限制回答在 100 字内。
2.  **📷 VR 即拍即识文物史料**：
    *   游客对景区碑刻、古树、展品进行拍照上传，页面会启动模拟的 3D 激光雷达（LIDAR）拓扑网格扫描动效，调用多模态大模型秒级识景，深度输出历史渊源。
3.  **📊 B端智慧运营大屏与 RAG 向量知识库**：
    *   提供包含实时客流走势、提问满意度情感倾向、问答热词云的数据看板。
    *   管理员可直接上传 PDF/Word 文件，系统自动解析并实现文本向量化（Embedding），热更新本地 RAG 库防 AI 幻觉，日结算定时任务（Vercel Cron）实现每日自动归档。

## 2. Demo 创作思路

### 💡 灵感来源
文旅市场在节假日旺季期间，面临着传统讲解器死板单一（无法交互）、人工导游价格昂贵（日均服务费高达 300-500 元）且供不应求的瓶颈。同时，老年群体在传统数字化景区中极易因复杂的交互和较弱的体能感到挫败。我们希望通过先进的多智能体协作（RAG + Tool Use + 适老偏好），做一款“懂人心、有温度”的数字伴游。

### 🎯 解决的社会痛点
*   **消除数字鸿沟**：让智能导游不再是年轻人的专利。通过针对银发群体的无障碍体验优化与针对儿童群体的童趣叙事，让多模态大模型的红利惠及全年龄段游客。
*   **杜绝事实幻觉**：传统的通用 AI 经常胡编乱造景区历史。本系统在 PostgreSQL 底层自建**余弦相似度 + 关键词重排**的双路 RAG，确保讲解句句考证有据。
*   **景区智慧化转型**：将客流、情绪统计以仪表盘可视化大屏形式实时反馈，使运营决策的周期由 24 小时缩短至分钟级，解决数据黑盒问题。

### 💎 方向的判断与取舍
*   **轻量终端 vs 大型3D引擎**：数字人小玉在客户端放弃了动辄几十兆、引起发热卡顿的 Unity/Three.js 引擎，采用纯 **SVG 矢量特征点 + 频域特征提取** 的技术方案，不到 **50KB** 实现超逼真唇形对齐，移动端秒开。
*   **双引擎动态容灾**：当主大模型（DeepSeek-V4-Pro）接口因访问超限发生 429 或 502 时，系统自动且零卡顿降级回退至 `deepseek.v3.1` 本地端点，确保游客伴游的连续性。

## 4. TRAE 实践过程

我们使用 Trae 作为主力 AI 协同编程 IDE。Trae 强大的 Agent 机制协助我们在极短的时间内重构了系统的核心排版与大模型重排路由逻辑，开发效率提升了 10 倍以上。

### 🛠️ 关键开发阶段与 Trae 实践

*   **第一阶段：数据模型建模与一键环境构建 (Database & Bootstrapping)**
    *   Trae 帮助我们设计了 spots、routes、qa_logs、knowledge_docs、analytics_daily 等 10 张 PostgreSQL 表物理分区 schema。
    *   同时，Trae 一键生成并调试了 `run.ps1` 脚本。该脚本能够在开发机上自动识别 `bun` 和 `npm`、自动判定 `.env` 环境变量文件是否存在，并在发生 Drizzle 结构冲突时自动回退执行 `db:push`，保障了一键热启动。
*   **第二阶段：前端极致交互 UI 的雕琢 (Interactive UX Fine-Tuning)**
    *   *单气泡加载过渡*：Trae 协助我们利用 React 状态机与 CSS 跳动动画，合并了原来的 loading 气泡与正文气泡，使得文本 SSE 流传输到达时原地流畅转化为打字机流，消除了页面重排抖动。
    *   *B端三列自适应弹性布局*：针对 `/admin/avatar` 大屏在小屏幕下表单重叠问题，Trae Agent 准确修改为 Flex 保护排版，锁定 `280px` 与 `360px` 两侧组件，用弹性分配解决适配 Bug。
*   **第三阶段：双模型动态回退机制的调试 (Failover System)**
    *   Trae Agent 编写了统一路由中间件。设定 3 秒应答超时阈值，并在后端实现了 SSE 拦截逻辑，拦截首行大模型的情感标签如 `[情感: 愉快]`，转化并传递给前端驱动嘴形动效。

## 5. 经验总结与开发心得

1.  **人机协同实现 10 倍速迭代**：在 React 19 + Next.js 16 如此前沿的技术栈搭配下，Trae 不仅没有表现出依赖滞后，反而能精准给出适配 Next.js App Router 的组件代码。AI 不再是单纯的“辅助提示词框”，而是可以真正理解我们的 CSS 像素对齐直觉、直接操作文件的全栈数字合伙人。
2.  **将无障碍融入产品底层**：在开发“银发模式”时，我们意识到“适老化改造”不能仅仅停留在“字体变大”，而是需要将大模型的 Prompt 语气放缓、在空间算法中过滤台阶等物理避障逻辑融入产品的底层架构，才能真正消除老年人的数字鸿沟。
3.  **细节决定产品的商业质感**：单气泡的流畅过渡与按钮的呼吸水波纹动画虽然微小，但在实际演示时，这些细节极大地提升了产品的体验质感。
